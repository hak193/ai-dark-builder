# AI Dark - Code Generator

## Project Overview
AI Dark is an innovative web application that harnesses the power of AI to assist users in generating code for various applications through an interactive chat interface. With a user-friendly design powered by Vue.js and styled with Tailwind CSS, AI Dark offers a seamless experience for users looking to prototype their applications efficiently.

## Installation
To run the AI Dark application locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/ai-dark.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd ai-dark
   ```
3. **Open the `index.html` file in a web browser.**

No additional packages need to be installed for this project as it relies on CDN links for its dependencies.

## Usage
Once you have opened the application, you can start using the AI Dark code generator by following these steps:

1. **Select a Template:** Click on the button that represents the type of application you want to create.
2. **Chat Interface:** Interact with the AI in the chat section by typing your application ideas directly into the text area and pressing Enter or clicking the send button.
3. **View Generated Code:** Switch to the Editor tab to see the generated code based on your input.
4. **Preview Your Application:** Switch to the Preview tab to test your generated application's functionality in a simulation environment.

## Features
- Interactive chat interface for real-time code generation.
- Code editing area for reviewing and copying the generated code.
- Preview section to simulate the output of the generated code.
- Clean, responsive design powered by Tailwind CSS.
- Vanilla JavaScript and Vue.js for easy learning and adaptation.

## Dependencies
This project utilizes several external libraries available via CDN:
- [Tailwind CSS](https://tailwindcss.com) for styling.
- [Vue.js](https://vuejs.org) for building the user interface.
- [Highlight.js](https://highlightjs.org) for syntax highlighting within the code editor.
- [Font Awesome](https://fontawesome.com) for icons.
- [Google Fonts - Inter](https://fonts.google.com/specimen/Inter) for typography.
